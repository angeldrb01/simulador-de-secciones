🔒 PDFs procesados localmente

1. Compatibilidad

Comprobamos si Chrome puede ejecutar su modelo local sin API, claves ni Ollama.

2. Documentación

Hasta 10 PDFs. El navegador distingue ficha técnica, manual y otros documentos. La ficha técnica se prioriza para datos eléctricos y el manual para secciones, bornes, protecciones y condiciones de instalación.

3. Páginas seleccionadas

Selección determinista previa a la IA. Las páginas relevantes se renderizan como imagen para que Gemini interprete tablas, celdas combinadas y valores comunes a varios modelos.

4. Datos extraídos

Política de fuentes: ficha técnica → datos eléctricos; manual → criterios/recomendaciones de instalación. Las tablas se interpretan visualmente con reintento automático y después se verifican contra el texto original del PDF. Número, significado y unidad/dimensión deben quedar demostrados antes de aceptar un dato.
